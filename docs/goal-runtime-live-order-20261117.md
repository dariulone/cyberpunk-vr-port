## Готовность и границы TM patch

Свежий standalone C++ analyzer build/self-test1/1 PASS; Lua root-lock/async fixture PASS; Python cleanup3/3 PASS; Python syntax/help PASS. Independent weapons review изменённых guard/cleanup/trace веток не нашёл blockers. CET actual loading/marker visibility/vehicle APIs ещё требуют первого live smoke. Root подтвердил новый mirror suite6/6 PASS; combined production build идёт отдельно.

TM patch исправляет утраченные AddRef и concurrent slot overwrite, сохраняет submitted source COM refs до существующего mirror fence. Max24 publication entries +4×24 submitted refs, без нового GPU allocation/fence/wait. Signal failure намеренно удерживает bounded pending refs и останавливает copy reuse. Это не доказательство placed backing heap lifetime: legacy transient resource может иметь внешнего heap owner. Отдельная preexisting CB/exposure raw publication race сообщена root и не включена в этот узкий patch. Current active SBS map-pair cause этим не установлен.
