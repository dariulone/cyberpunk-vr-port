# Controller artwork

The controller illustrations embedded unchanged in `cyberfinger-controls.svg`
and `cyberfinger-controls.html` come from `D:\build\CyberFinger_SteamVRFusion`:

- `resources/icons/steamvr_cybrfngr_left_transp.png`
- `resources/icons/steamvr_cybrfngr_right_transp.png`

Their control positions follow that repository's `docs/manual/manual.html`.
The source repository's GPL license is reproduced in
[ARTWORK-LICENSE.txt](ARTWORK-LICENSE.txt) for the embedded artwork. The diagram's
labels and generator belong to this project; the artwork retains its source
license. These are the existing controller illustrations, not new photographs.

Regenerate from the repository root with
`python scripts/generate_cyberfinger_diagram.py --driver D:\build\CyberFinger_SteamVRFusion`.
