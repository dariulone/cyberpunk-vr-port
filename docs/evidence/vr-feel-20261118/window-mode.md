# Режим окна в VR

На этой системе с OpenXR Simulator и настройками игрока оставлен BorderlessWindowed. При включённой генерации оба режима удерживают целевые 45 исходных кадров/с. При отключённых framegen и ограничителе у fullscreen средняя скорость выше примерно на 1,6 кадра/с, но результаты отдельных окон перекрываются. Данных для смены режима по умолчанию на всех системах недостаточно.

| Настройки | Borderless, исходные FPS | Fullscreen, исходные FPS |
|---|---:|---:|
| Текущий профиль с framegen | 45,03 / 44,97 | 45,01 / 44,99 |
| Framegen и ограничитель отключены | 58,65 / 60,33 | 62,52 / 59,62 |

Оба сравнения выполнены в одном процессе на AutoSave-7 со статичной камерой. Для каждой строки порядок был borderless → fullscreen → fullscreen → borderless. После стабилизации режима собиралось девять секунд реальных кадров за окно. Тестовая сборка пропускала запрос эксклюзивного fullscreen к DXGI. Переходы подтверждены успешным `GetFullscreenState`, размер буфера оставался 5296 × 2864. После измерения восстановлены исходный режим игры, лимит кадров, генерация и видимость счётчика.
